# 🤲 Guide de Contribution - CED HalalTech™

> *"La religion, c'est le conseil (Nasihah)."* (Hadith)

Bienvenue dans l'écosystème **CED HalalTech™**. Contribuer ici n'est pas seulement écrire du code, c'est participer à un projet éthique, souverain et utile à la Oummah.

Avant de soumettre ta première contribution, merci de lire attentivement ce guide qui reflète notre engagement pour le **Wasatiyyah (Juste Milieu)**.

---

## 🏳️ 1. Prérequis Spirituels & Éthiques

Avant toute ligne de code, assure-toi d'avoir :
1.  **Lu le Manifeste Wasatiyyah** : [`00_CONSTITUTION_ETIQUE/MANIFESTE_WASATIYYAH.md`](./00_CONSTITUTION_ETIQUE/MANIFESTE_WASATIYYAH.md)
2.  **Compris la Niyyah Globale** : [`00_CONSTITUTION_ETIQUE/NIYYAH_GLOBALE.md`](./00_CONSTITUTION_ETIQUE/NIYYAH_GLOBALE.md)
3.  **Accepté la Charte Couleur** : Chaque fichier et commentaire doit respecter la charte (Beige, Bleu, Vert, etc.).

Si ton code contient une logique de **Riba** (intérêt), **Gharar** (tromperie) ou **Maysir** (jeu/spéculation), il sera rejeté, aussi brillant soit-il techniquement.

---

## 🎨 2. Standards de Code (Wasatiyyah Coding)

Nous privilégions la clarté et la sobriété à la complexité.

### 2.1. Charte Couleur dans le Code
Chaque section de code doit être préfixée par l'émoji correspondant à son domaine :
```python
# 🟦 [INFRA] Connexion base de données
# 🟩 [FINANCE] Calcul de la Zakat
# 🟪 [IA] Filtre éthique
# 🟥 [SECURITE] Validation des tokens

2.2. Sobriété Énergétique
Évite les boucles inutiles.
Optimise les requêtes SQL.
Minimise la taille des assets envoyés au client.
Question à se poser avant de commiter : "Ce code consomme-t-il plus de ressources que nécessaire ?"
2.3. Nommage des Fichiers
Les fichiers techniques dans les dossiers dédiés doivent inclure l'émoji de couleur si cela améliore la lisibilité (ex: 🟦_docker-compose.yml, 🟦_deploy.sh).

🔄 3. Processus de Contribution (Shura Technique)
Fork le dépôt.
Crée une branche dédiée : feat/nom-de-la-fonctionnalite ou fix/nom-du-bug.
Code ta fonctionnalité en respectant les standards ci-dessus.
Auto-Revue : Vérifie toi-même que ton code est propre et éthique.
Soumets une Pull Request (PR).
La Double Validation Obligatoire
Toute PR sera soumise à deux revues avant fusion :

Revue Technique : Qualité du code, tests, performance (par le Lead Tech).
Revue Éthique : Conformité au Manifeste Wasatiyyah (par le Responsable Éthique).
⚠️ Une PR validée techniquement mais refusée éthiquement sera fermée sans hésitation.

📢 4. Code de Conduite (Adab)
Nous sommes une communauté fondée sur la fraternité (Ukhuwwah).

Zéro tolérance pour le harcèlement, le racisme, le sexisme ou l'irrespect.
La critique doit être constructive et bienveillante. On critique le code, jamais la personne.
En cas de conflit, réfère-toi à la Charte Shura : 04_GOUVERNANCE_ET_HUMAIN/CHARTE_SHURA.md
